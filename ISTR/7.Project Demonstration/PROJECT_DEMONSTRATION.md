## 📌 About the Project

**Intergalactic Space Travel Request (ISTR)** is an enterprise workflow automation application developed using the **ServiceNow App Engine Platform**. The application digitizes the complete mission request lifecycle by providing a centralized Service Catalog interface, automated approval workflows, role-based security, business automation, reporting, and analytics to improve operational efficiency and transparency.
